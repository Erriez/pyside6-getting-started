# Code of Conduct

This project is maintained in my spare time. Please be aware that I may not always have the
availability to review issues or pull requests quickly. Response times may vary.

---

## Issues

When opening an issue, please include:

- A clear description of the problem. Please refer to [CONTRIBUTING.md](CONTRIBUTING.md)
- A minimal and complete testcase or reproduction  
- The exact versions of Python, PySide6, and the operating system you used  

Issues without a reproducible testcase may be closed without investigation.

---

## Pull Requests

Pull requests are welcome, but they must:

- Be focused and easy to review  
- Include a clear explanation of the change  
- Avoid unnecessary refactoring or formatting-only changes  
- Stay within the scope of Windows / Linux / Raspberry Pi OS desktop environments  
- Not introduce new external dependencies or submodules  

I may not be able to review PRs immediately, and review times may vary.

---

## General Conduct

Please keep all communication respectful, constructive, and considerate.  
This project exists to help the community, and contributions, ideas, and improvements are 
appreciated.

Harassment, discrimination, or disrespectful behavior of any kind will not be tolerated.

---

## Scope

This Code of Conduct applies to all interactions within:

- GitHub Issues  
- Pull Requests  
- Discussions  
- Any other project-related communication channels
